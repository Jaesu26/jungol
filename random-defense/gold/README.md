# Gold Random Defense

코드포스 레이팅을 올리기 위한 골랜디를 해보자~

## 못 풀거나 스킵한 문제 목록

`1.` [소의 해](https://jungol.co.kr/problem/5294): $O\left(N^2\right)$보다 빠르게 풀 수 있는 방법을 모르겠다

`2.` [세 줄로 타일 깔기(3열로 타일깔기)](https://jungol.co.kr/problem/2112): 힌트를 보면 안 된다. 정답이 아예 나와있음..

`3.` [숨은 곰](https://jungol.co.kr/problem/5631): $O\left(N^2\right)$보다 빠른 시간에 못풀겠다

`4.` [매우 즐거운 주말농장](https://jungol.co.kr/problem/5859): $20$분 정도 고민했는데 $O\left(N^2\right)$보다 빠른 풀이를 못찾을 것 같다

`5.` [경로찾기(find route)](https://jungol.co.kr/problem/1008): $2$시간 동안 고통 받으며 얻은 결론은 $O\left(tn^2\right)$ 알고리즘으론 통과할 수 없다는 것이다. 물론 가지치기도 적용했다. 중간에서 만나기를 활용하면 될지도 모르겠다

`6.` [정수 팰린드롬 돌게임](https://jungol.co.kr/problem/8141): 진짜 모르겠음, 레전드 애드 혹 문제

`7.` [Moo Hunt](https://jungol.co.kr/problem/8929): 중간에 일이 생겨서 그만뒀다. 백트래킹으로 풀 수 있을 것 같다

`8.` [스타크래프트 토너먼트](https://jungol.co.kr/problem/2111): $1$시간 동안 못풀고 때려쳤다. 수학 문제이다

`9.` [마트리곤](https://jungol.co.kr/problem/10405?cursor=InVfMTQ5NTIyIiwwLDc=): 입력 범위가 안 나와 있어요....

`10.` [피자가게](https://jungol.co.kr/problem/1798): $2$시간 동안 못풀고 포기했다. 이 문제는 내가 예전에 골랜디로 푼 [상근이의 레스토랑](https://www.acmicpc.net/problem/2786)과 동일한 문제이다. 전에 푼 거 보니까 증명에 보충 설명이 필요한 부분이 있다. 일반적인 방식과 조금 다르게 풀었고 설명이 조금 모자라서 예전에 푼 방법이 생각나지 않았던 것 같다. 기존 정보를 기반으로 확장시키는 아이디어가 필요하다. 근데 그건 차치하고 못푼 게 말이 안 된다. 풀이를 보면 되게 쉬운데 엄... 야간 근무의 폐해라고 믿겠다
